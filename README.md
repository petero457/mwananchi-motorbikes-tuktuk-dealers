# Mwananchi Motorbike & Tuk Tuk Dealers

Frontend prototype built with React + Vite using the supplied vehicle photos and logo.

## Business configuration
-- Ecobank Towers, Muindi Mbingu Street, Nairobi, Kenya
- Delivery across Kenya
- Motorbike deposit: KSh 15,000
- Tuk-tuk deposit: KSh 30,000
- Daily instalment: KSh 150
- Period: 21 months
- Call/support: 0786 275 195
- WhatsApp: 0751 604 649
- Financing applications include a guarantor and are subject to verification/assessment.

## Run
```bash
pnpm install
pnpm dev
```

Or:
```bash
npm install
npm run dev
```

## Important before launch
The application form is frontend-only in this prototype. Connect it to a secure backend/database before collecting real ID/KRA/guarantor information.

The review and recent-purchase areas intentionally contain placeholders until genuine customer reviews and verified transactions are available.
